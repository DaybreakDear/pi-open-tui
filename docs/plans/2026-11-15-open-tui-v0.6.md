## 0. 根因结论（已用字节级探针证实，勿再重复推导）

### R1 `P0` 外观页切主题"没反应" — 真缺陷

- `extensions/open-tui/index.ts:532-541` 改主题时只做 `skinEpoch += 1`，然后 `config = nextConfig`。
- `extensions/open-tui/index.ts:575` 变更结束只调 `requestFooterRender?.()`；该钩子在 `extensions/open-tui/footer.ts:589` 是 `() => tui.requestRender()`。**只重绘，不失效。**
- `node_modules/@earendil-works/pi-tui/dist/components/markdown.js:214-221` 的 `invalidate()` 清 `cachedText/cachedWidth/cachedLines`；`:227` 的命中条件是「文本 + 宽度」，**主题不在缓存键里**。
- 探针实测：改配置后不 invalidate 重渲染 → 输出逐字节相同；`md.invalidate()` 后 → 输出变化。
- Pi 自己的 `/settings` 切主题为什么灵：`node_modules/@earendil-works/pi-coding-agent/dist/modes/interactive/theme/theme-controller.js:205-207` `notifyChanged() { this.ui.invalidate(); this.onChanged(); }`。
- 会重绘的面：底栏、设置浮层自身、编辑器、复制按钮。**不会重绘的面**：用户消息气泡（`divider` 与 `userBar` 都从这里出）、助手 markdown 正文、已画出的 compact 工具行。

### R2 `P0` 轮次分隔线看不见 — 预设取值缺陷

- 绘制链路正常：`extensions/open-tui/markdown-skin.ts:61-68` 给新用户消息前置 `---`，`:88-95` 的 `renderToken` 补丁把它画成 `divider` 槽颜色。
- 问题是亮度：`extensions/open-tui/theme.ts:93-110` `PRESET_SLOTS["tokyo-night"].divider = "#3b4261"`，对用户气泡底 `#24283b` 只有 **1.48:1**，对页面底 `#1a1b26` 只有 **1.74:1**，低于 WCAG 非文本 3:1。
- `extensions/open-tui/config.ts:151-159` `DEFAULT_CONFIG.theme.preset` 就是 `"tokyo-night"`，所以默认装完就是 1.48:1。

### R3 `P0` 思考块耗时 / token 看不见 — 静默失效

- 现在的实现是**劫持 Pi 的"隐藏思考"标签**：`extensions/open-tui/index.ts:105-114` → `extensions/open-tui/editor.ts:678-686` → `extensions/open-tui/editor.ts:541-563` 改那个组件的 `render`。
- Pi 只在思考**被隐藏**时渲染该标签：`node_modules/@earendil-works/pi-coding-agent/dist/modes/interactive/components/assistant-message.js:130-143` `const thinkingComponent = hidden ? new Text(...hiddenThinkingLabel...) : markdownBlock("thinking", ...)`。
- `node_modules/@earendil-works/pi-coding-agent/dist/core/settings-defaults.js:26` `hideThinkingBlock: false`，且 `C:/Users/Bingo/.pi/agent/settings.json` 没有这个键 → 思考块可见 → 标签组件根本不进渲染树。
- 探针实测：`hideThinkingBlock=false` 时注入的 `PEEK 12.3s . 1.2k tok` 在输出里**完全不存在**；`true` 时出现在思考那行。失败是静默的，无报错。
- 附带缺陷：`extensions/open-tui/peek.ts:215-216` 的 `done` 分支只返回 `prefix + glyphs.done`，不带计数；`index.ts:422` 在 `phase === "done"` 后停止更新。

### R4 `P1` 命令输出竖线看不见 — 前置条件未写清 + 颜色过暗

- `extensions/open-tui/tool-view.ts:748-751`：只有 `view.mode === "compact"` 才接管渲染，否则返回 Pi 原生渲染器。
- `extensions/open-tui/config.ts:141-145` `DEFAULT_CONFIG.toolView.mode = "native"`，线上配置也是 `"native"` → compact 行从未产生 → `paint("gutter", …)`（`tool-view.ts:629,686,690`）从未执行。

- 文档 `README.md:92`、`docs/configuration.md:108`、`README.zh-CN.md:92` 都没写"需要 compact"。

### R5 设置页信息架构 — 无缺陷，是认知错位

- 主题 5 行在 `settings-command.ts:312-339`，属于 **Appearance / 外观**（tab id 是 `icons`）：`mode` / `cursorStyle` / `currency` / `usdToCny` / `switchable` / `themePreset` / `dividers` / `themeGutter` / `themeBanding` / `themeUserBar`，共 13 显示行，无重复、≥18 行终端不裁切、保存确实落盘。

## 2. 全局约定（沿用，不得违反）

- TDD：红测试 → 实现 → 绿 → 提交。红测试单独提交。
- 提交信息用 Conventional Commits + 中文正文；一个任务一个提交。
- 不新增运行时依赖；测试用 `node --test`，跑 `.ts` 靠 Node 类型剥离。
- 新建的测试文件必须同时加进 `package.json` 的 `scripts.test` 清单。
- 所有 `render` 补丁必须**确定性**：同样的 `(width, text)` 必须得到同样的字节。时间戳一律缓存，禁止在 `render` 里读 `Date.now()`。
- 所有补丁必须可逆：`cleanup()` 还原原型、清模块级状态；安装顺序与清理顺序严格反序。
- 宽度预算：任何加列/加行的装饰都必须先把可用宽度减下去，再调原始 `render`；原始行溢出时整体回退到不带装饰的调用。
- 不许把装饰写进 `this.text`（`copy-buttons.ts:456` 直接复制 `this.text`）。

### V0.6-1 `P0` 主题变更后强制重绘（修 R1）

**目标**：外观页切任何视觉项后，已画出的消息立刻按新配色重绘。

**测试**（新建 `tests/repaint.test.ts`）

**验收**：外观页把 preset 从 tokyo-night 切到 gruvbox-dark，屏幕上已存在的助手正文与用户气泡立刻变色，不需要重启、不需要等新消息。

### V0.6-7 `P1` 消息时间戳

**目标**：助手有气泡时时间戳嵌在气泡顶边框右端；无气泡时走首行前缀；用户消息永远走右侧空白行；不额外占行。

**测试**（新建 `tests/timestamps.test.ts`）

- T7.1 组件带 ISO `timestamp` 字段（恢复会话路径）→ 渲染 `HH:MM`。
- T7.2 助手组件只有 `lastMessage.timestamp`（毫秒，实时路径）→ 用本地时间格式化。
- T7.3 两者都没有 → 用首次渲染打点，且同一组件二次渲染时间戳**不变**（确定性）。
- T7.4 `timestamps: "off"` → 逐字节等同未安装。
- T7.5 宽度不足（如 < 24）→ 不写时间戳，不破坏 `width` 约束。
- T7.6 用户消息：写在**首行**（Pi 的 `Markdown` 有 `paddingY = 1` 顶部空白行，`user-message.js:42` 的第三参数），不覆盖 `[Copy]` 占用的末行。

**实现**

- 新建 `extensions/open-tui/timestamps.ts`，最后安装（在气泡之后），这样能往边框行写字。
- 数据来源三档：`(this as any).timestamp`（ISO，恢复路径）→ 助手 `this.lastMessage?.timestamp`（毫秒）→ `WeakMap<object, string>` 首次渲染快照。**三者统一成本地时刻再格式化。**
- 配置：`theme.timestamps: "all" | "assistant" | "off"`，默认 `"all"`。
